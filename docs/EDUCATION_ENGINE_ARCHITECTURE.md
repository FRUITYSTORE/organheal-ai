# OrganHeal Education Engine

## Goal

Help users quickly understand their health results and know what to do next.

## Main User Paths

1. Learn from my results
2. Understand a lab marker
3. Learn by organ
4. Prepare for my doctor
5. Improve my lifestyle

## Learning Module

Each topic should be a learning module, not only an article.

A module may include:

- Short explanation
- Short video
- Key points
- Lifestyle actions
- Questions for the doctor
- Related lab markers
- Related organs
- Related topics
- Future AI explanation

## First Modules

10. Hemoglobin

## Simple User Flow

User uploads report
-> OrganHeal detects important markers
-> User sees recommended learning
-> User opens one short module
-> User gets simple next actions

## Design Rules

- No crowded library layout
- No repeated sections
- No long medical wording
- One clear next action
- Simple language
- Strong visual clarity
- Videos support learning but do not replace written modules
